# Burger King Practice Site
버거킹 브랜드 사이트 퍼블리싱 실습 예제 (학습용, 실제 브랜드 사이트가 아닙니다)

## 배포 (GitHub Pages)
1. 새 저장소를 만들고 이 폴더의 파일을 모두 올립니다.
2. Settings → Pages → Branch: `main` / `/ (root)` 선택 후 Save
3. `https://<아이디>.github.io/<저장소명>/` 에서 확인

## 구조
- `index.html` : 헤더, 슬라이더, 타일, 스토리, 이벤트, 매장 찾기
- `css/style.css` : 스타일 및 반응형(1024 / 760 / 480)
- `js/main.js` : 메뉴, 슬라이더, 숫자 카운트, 매장 검색
- `img/` : 이미지를 넣을 폴더 (현재는 이모지로 대체)
